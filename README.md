# Glasses apps

Meta Ray-Ban Display web apps for Home Assistant.

- `home/` – switch entities labelled **Glasses** on and off
- `door/` – live Blue Iris front door camera

Add in the Meta AI app as `https://adrianhealey.github.io/glasses/home/#token=YOUR_HA_LONG_LIVED_TOKEN` (and `/door/`).
The token stays after the `#`, so it is never sent to GitHub. Never commit a token to this repo.
